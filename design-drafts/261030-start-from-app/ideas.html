Redesign the waiting screen popup

The user arrives from app.eklipse.gg with a clip and a template already picked. Loading takes 2 s at P75. Today a 4-step checklist card sits on top of a dimmed poster: there's too much to read in 2 seconds, it covers the stage, and it never shows the template the user chose. Three alternatives below, each with a different structure. Use the switches to try every scenario, a slow load and a failed load. Each mock is the editor at reduced size: rail, panel, stage and timeline.
