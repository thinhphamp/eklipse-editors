# Design drafts

One folder per design section, one feature each: `<YYMMDD>-<feature>/` with `brief.md`, `ideas.html`, optional
`variants/` and `decisions.md`. Nothing here is the final design; a variant moves into
`prototypes-src/claude-improvement/` only after the user confirms it. Workflow: `.claude/skills/eklipse-design-sandbox/SKILL.md`.
