Elements: production's organisation, prototype's style

Production splits Elements into top tabs (Meme · Audio · Texts · Effects) with sub-tabs, a search bar and a media grid. The prototype has one long scroll of sections and no memes at all. Audio stays its own rail tab, so Elements becomes Meme · Texts · Effects.

Three ways to do it below. Every mock is clickable: tabs, sub-tabs, search, grid size, adding a tile. Use the scenario chips to switch between first-time, returning, after AI Edit and no-results states.

A · Production port

Same tabs as production, nothing more

Top tabs Meme · Texts · Effects, underline sub-tabs, search with a Search button, grid-size toggle. Returning users from production find everything where it was.

How it works

  • Opens on Meme → Memes. Tabs and sub-tab are remembered per user.
  • Search applies to the open sub-tab only, like production.
  • Tiles show length and a sound icon for memes with audio; hover plays the preview, + Add or click adds at the playhead and opens today's edit page.
  • Grid toggle: 3 columns (default) or 2 large.

Pros

  • Zero relearning for production users; easiest port.
  • Each tab is short and focused.

Cons

  • Search finds nothing if you're in the wrong sub-tab ("GG" is a GIF, not a meme).
  • Three levels (tab → sub-tab → tile) before anything is added.
  • No view of what is already on the clip (AI memes).

Edge cases

  • No results: message + "Clear search".
  • Uploads empty: upload box only (10 MB, png/jpeg/gif, premium as today).
  • 16:9 clip: memes are added at the same size, centred on the game area.
B · Recommended

Production tabs + one search + "On this clip"

Same Meme · Texts · Effects tabs, plus an All tab with a shelf per type, one search across every tab, and a strip of the elements already on the clip.

How it works

  • All (default): Recently used (returning users), then a shelf for Memes, Texts, GIFs, Stickers, Emotes, Effects; "See all" opens that tab.
  • One search on top, sticky. Tabs show result counts, so "GG" in Meme says "0" and All shows it under GIFs.
  • On this clip: what's already added, AI items tagged. Click to edit, × to remove. Hidden when the clip is empty.
  • Sub-tabs become pills (prototype style) inside each tab.

Pros

  • Production structure is still there for people who know it.
  • Search can't miss because of the wrong tab.
  • Fixing AI memes in one place; repo data: untouched AI memes export 44.4% vs 72.9% when edited.

Cons

  • One more tab than production.
  • On this clip repeats the timeline; needs to stay one row.

Edge cases

  • First time: no Recent, no On this clip; All starts with Memes.
  • After AI Edit: 3 AI memes listed with "AI" tag and "Swap" in the edit page.
  • No results anywhere: suggests GIFs/Emotes search terms and Upload.
  • Many items on clip: chips wrap to 2 rows, then "+N more".
C · Drill-in

Three big doors, then a full gallery

Elements opens on three category cards (Meme, Texts, Effects) with a live peek. Pick one to get production's gallery with sub-tabs; back returns to the doors.

How it works

  • Landing: search, three cards with 3 previews each, Recently used (returning), Upload row.
  • Card → gallery page, "← Elements", pills for sub-tabs, grid toggle (same as the prototype's "Full page" today).
  • Searching on the landing shows results grouped by type.

Pros

  • Calm first screen; the three types are obvious to first-time users.
  • Gallery pages get the full panel height.
  • Works the same on a narrow/mobile panel.

Cons

  • Always one extra click before a meme, for the heavy users who add memes most.
  • Further from production's layout than A or B.

Edge cases

  • First time: no Recent row.
  • No results: grouped empty state with Upload.
  • Back keeps the search and scroll position.

  3. Meme sub-tabs: production shows only "Meme". Are GIFs, stickers and emotes elsewhere in production, or new here?
