B2 · Channel stickers: pick a look, make it yours, add as many as you need

Built on B (look first, settings in a sheet) with your round-1 answers. Click stickers on the preview, add a second sticker, change names, tint any look, drag the time slider to see when each one shows.

1 · Names per platform, several stickersYour channels keep one name each. A clip can carry up to 3 stickers.
2 · "Channel stickers"Rail tab name, 2nd after Templates.
3 · One libraryEklipse and StreamLadder looks in one grid, no source labels, each look once.
4 · Tint everythingEvery look recolours. "Original" keeps the look's own colours.

How it works

  • On this clip lists the stickers on the clip (up to 3). Click one to edit it; the grid then changes that sticker's look.
  • + Add sticker switches the grid to "add": picking a look adds a new sticker with your last used platform.
  • Your channels are saved once (platform + name). Editing a name updates every sticker that uses it.
  • Multi looks show each name next to its icon when names differ.
  • When: whole clip, first 5 s or last 5 s. Stickers that show at the same time stack upwards automatically.

Remembered

  • Channels and names: local storage, every clip.
  • Use these stickers on new clips (on by default): the whole set, with looks, colours and timing.
  • Saved templates carry the sticker set.
  • New stickers start on the last platform you picked.

Edge cases in the mock

  • First time: no channels; picking a look asks for the name, field highlighted.
  • 3 stickers: Add is disabled with a reason.
  • All removed: empty "On this clip" state; the grid adds.
  • Single look on a 2-platform sticker: keeps the first platform, with Undo.
  • Long name: text shrinks; 24-character cap.
  • 16:9 clip: stickers stack bottom-left.
